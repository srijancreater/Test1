# Bid / No-Bid Checklist

Run every tender that Tender Radar surfaces through this list before committing bid effort.
Score each line 0 (no) / 1 (partly) / 2 (yes). **≥ 24 of 32 → Bid. 16–23 → Bid only with a partner. < 16 → No-bid.**

## 1. Eligibility (any hard "no" here = No-bid, regardless of score)
| # | Question | Score |
|---|----------|-------|
| 1 | Do we meet the **average annual turnover** requirement (or can a consortium partner)? | |
| 2 | Do we have the required **number and value of similar completed projects** (work orders + completion certificates)? | |
| 3 | Do we hold mandatory **certifications** (ISO 9001 / 27001 / 20000, CMMI level, STQC, MeitY empanelment)? | |
| 4 | Are we registered on the **portal** used (GeM, CPPP / eProcure, state e-procurement) with a valid DSC? | |
| 5 | Can we arrange the **EMD / bid security** and later the **performance bank guarantee**? | |
| 6 | Are **MSE / startup exemptions** (EMD, turnover, experience) applicable to us? | |
| 7 | Is there **no blacklisting / conflict-of-interest** issue? | |
| 8 | Is **consortium / subcontracting** allowed if we need it? | |

## 2. Fit
| # | Question | Score |
|---|----------|-------|
| 9 | Does the scope sit in one of our **10 target categories** (Tender Radar score ≥ 10)? | |
| 10 | Do we have a **reusable asset** (accelerator, demo, prior codebase) for ≥ 40 % of the scope? | |
| 11 | Can we field the **key personnel** demanded in the RFP (CVs, qualifications, years)? | |
| 12 | Are **data-residency / on-prem / sovereign-cloud** constraints ones we can meet? | |

## 3. Commercials & risk
| # | Question | Score |
|---|----------|-------|
| 13 | Is the **estimated value** worth the bid cost (target ≥ 20× bid-prep cost)? | |
| 14 | Are **payment milestones** acceptable (not back-loaded to go-live / acceptance only)? | |
| 15 | Are **SLA penalties and LD caps** reasonable (LD ≤ 10 % of contract value)? | |
| 16 | Is the **selection method** favourable (QCBS beats L1 for AI work)? | |

## 4. Win probability
- Do we know the **buyer** or have prior work with the department?
- Was the RFP **shaped by a competitor** (very specific product names, odd eligibility)?
- Can we attend the **pre-bid meeting** and submit queries before the deadline?
- Is there a **PoC / demo round** where our product can win on merit?
